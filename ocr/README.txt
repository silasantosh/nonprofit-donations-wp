Offline reader for payment screenshots. Runs only inside the donor's own browser; the picture is never uploaded.
Bundled open-source parts (Apache-2.0, GPL-compatible):
- tesseract.js 5.1.1 (tesseract.min.js, worker.min.js) https://github.com/naptha/tesseract.js
- tesseract.js-core 5.1.1 (tesseract-core-*.wasm.js) https://github.com/naptha/tesseract.js-core  (Tesseract OCR engine, Google, Apache-2.0)
- eng.traineddata: tessdata_fast English model, https://github.com/tesseract-ocr/tessdata_fast (Apache-2.0)
npd-parse.js and npd-shot.js are part of this plugin (GPL-2.0-or-later).
